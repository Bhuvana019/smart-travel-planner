Engineering Blueprint

About Smart Travel Planner

A modern, frontend-first travel management system designed for intuitive itinerary building, dynamic budget calculations, and destination experiences.

Design Principles

Frontend-First Engineering

Before touching backend servers, database schemas, or third-party APIs, we validate every user interaction, form workflow, modal behavior, and responsive layout.

This prototype delivers full client interactivity powered by temporary in-memory and local storage demo data — featuring Arun Kumar's 4-day trip to Goa (₹25,000 budget, 3 travelers).

Phase Roadmap

Phase 1 (Current)
Frontend UX & Templates

HTML5, CSS3, Vanilla JS, Jinja2 templates, interactive validation, demo data.

Phase 2
FastAPI & Persistence

FastAPI endpoints, SQLAlchemy models, database, real CRUD & auth.

Phase 3
Experience Finder API

Backend proxy integration to external recommendations API.

System Boundary

Clear Architectural Isolation

Strict separation ensures the client browser never contacts external vendor APIs directly.
